# Changelog

## v1.0.0

- Daily AI + defense + robotics Telegram bulletin
- Weekly trend report workflow
- RSS, Google News RSS, and arXiv source collection
- Category-based scoring and deduplication
- Gemini-generated Turkish analysis
- Public/template repository support
- Security docs, issue templates, and `.gitignore`

## Unreleased - Telegram formatting improvements

- Switched Gemini output from free-form Markdown text to strict JSON.
- Added Telegram HTML rendering with clickable source labels instead of long raw Google News URLs.
- Added compact card-style daily bulletin format.
- Reduced default daily bulletin items to 6 for readability.
- Disabled web page previews by default to keep Telegram messages clean.
- Improved message splitting so cards are not broken in the middle.
